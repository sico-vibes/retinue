# Projects

A project is a piece of work that has a folder on your PC and a team of employees. Each employee works in that folder, so they see the same code, documents and history you do.

![The sidebar with projects](/docs/docs-team-dark.webp)

## Create a project

1. Open the plus menu in the sidebar and choose **New project**.
2. Give the project a name.
3. Choose the folder on your PC where the work lives. This becomes the working folder for the employees on the project.
4. Hire employees for the project, or ask the CEO to propose a team. See [The CEO and delegation](/docs/the-ceo-and-delegation/).

## Working folders

Each employee's working folder is shown on its page. A project's employees normally share the project folder. If an employee needs a different folder, change it in its settings.

## Good to know

- Employees on the same project see the same files, so their changes can affect each other. Review the changes before you accept them. See [Reviewing changes and pull requests](/docs/reviewing-changes-and-pull-requests/).
