# Your first conversation

A conversation is a thread with one employee. It keeps the messages, the work the employee did and the decisions you made, so you can come back to it later. You can have many conversations with the same employee, one for each piece of work.

![A conversation with an employee](/docs/docs-main-dark.webp)

## Steps

1. Select the employee in the sidebar.
2. Choose **New conversation**, or press the new conversation button in the top bar.
3. Type what you want in the message box at the bottom. Be specific. For example: "Check the tests in this project and tell me which ones fail."
4. Press **Send**.
5. Watch the reply come in. The employee may show steps as it works, such as reading a file or running a command.
6. If it asks for permission, read the request and choose to allow it or not. See [Approvals and permissions](/docs/approvals-and-permissions/).
7. When the work is done, read the summary. Ask follow-up questions in the same conversation, so it keeps the context.

## Mention an employee

In the message box, type `@` and a name to point a message at a particular employee, for example `@Ada`. This is useful when you have several employees in one project.

## Good to know

- You do not need to write perfect instructions. Start simple, then correct the employee as it goes.
- If you send a message while the employee is still working, it joins a queue. See [Messages, the queue and steering](/docs/messages-the-queue-and-steering/).
- To look at the changes the employee made, open **Review**. See [Reviewing changes and pull requests](/docs/reviewing-changes-and-pull-requests/).
- Starting a new conversation does not delete the old one. You can find it in the list of conversations.
