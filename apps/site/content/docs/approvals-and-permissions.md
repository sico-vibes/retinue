# Approvals and permissions

Before an employee runs a command or changes a file, it can ask you first. The approval mode decides when it asks. You choose the mode for each employee, and you can set a default for employees that have no mode of their own.

![Approval requests waiting for you](/docs/docs-approvals-dark.webp)

## The four modes

- **Ask first.** Nothing changes until you approve each action. This is the default for new employees.
- **Auto-accept edits.** The employee can change files without asking. It still asks before it runs commands.
- **Auto-approve.** Safe actions go through. Risky ones still ask you.
- **Full access.** Actions run without asking. Scheduled work still uses safe actions only.

## Steps: answer an approval request

1. When an employee needs permission, a request appears in the conversation and, if the app is in the background, in the companion.
2. Read what the employee wants to do: the command, or the file it will change.
3. Choose to allow it, or to deny it.
4. If you are not ready to decide, choose **Later**. The request is set aside for five minutes, then comes back.

## Change the mode

1. Open the employee's settings.
2. Choose the approval mode you want.
3. For **Full access**, Retinue asks you to confirm first.

To change the default for every employee without its own setting, open Settings, Approvals.

## Good to know

- **Full access** means the employee acts without asking, in every project it works on. Use it only in projects you trust.
- If you need to stop everything at once, choose **Pause all agents**. Scheduled runs pause too, until you turn them back on.
