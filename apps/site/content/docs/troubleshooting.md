# Troubleshooting

Most problems have a simple fix. Start with the one that matches what you see.

## A coding agent is not listed

1. Check that it is installed and that you have signed in to it once.
2. Choose **Scan for agents** in Retinue.
3. If it still does not appear, turn it on under Settings, then Coding agents, then Providers.

## A conversation stopped

1. Read the message in the conversation. It says what went wrong, in plain words.
2. If a usage limit was reached, the message box shows when it resets. You can let the conversation resume then, or snooze it.
3. If the work failed, choose **Ask the CEO to troubleshoot**. The CEO opens a conversation with the facts and suggests what to do.

## An approval request is stuck

1. Open the conversation and check the request.
2. Choose to allow it, deny it, or choose **Later**.

## A coding agent's sign-in has expired

Retinue flags the coding agent and offers to fix the sign-in. Follow the steps in the sign-in window, then return to Retinue.

## The installer will not run

See [Install Retinue](/docs/install-retinue/), which explains the Defender and SmartScreen warnings for early betas.

## Still stuck?

Check the release notes for the version you have, then report the problem on [the Retinue issues page](https://github.com/sico-vibes/retinue/issues). Say what you did, what you expected and what happened.

## Good to know

- Retinue shows unknown values as unknown. If a number is missing, the coding agent did not report it.
- Back up your data before you try a big change. See [Privacy and your data](/docs/privacy-and-your-data/).
