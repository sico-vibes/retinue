# Retinue 0.2.0-beta.2

Watch the computer on your server from inside Retinue, and take control when you need to.

## New

- **The computer's screen inside Retinue.** Open the Computer card in a conversation's side panel, or **Open the screen** in Settings › Integrations › Computer. The screen opens in **Watching**: employees use it and nothing you do reaches it. Choose **Take control** to use the mouse and keyboard yourself, and **Watching** to hand it back. Retinue shows the screen through its own backend, so the window never holds your computer token.

## Changed

- When the screen can't be shown, the window now says why (for example, the computer is asleep, or your server doesn't offer its screen to Retinue yet) and offers to open it in your browser.

## Fixed

- The Machines page said a machine needs the Chat level to take a conversation over. It needs Operator, and now says so.

## Before you use it

Your Harbor server has to accept the computer token on its screen page. A Harbor set up from Retinue's setup prompt does; an older one shows the screen only to your own browser sign-in, and Retinue then opens it in your browser.

## Installation

Download `Retinue_0.2.0-beta.2_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
