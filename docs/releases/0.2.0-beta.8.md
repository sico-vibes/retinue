# Retinue 0.2.0-beta.8

Antigravity's sign-in now shows correctly, and scanning for coding agents is faster.

## Fixed

- **Antigravity showed "Sign-in status unknown" even when you were signed in.** Retinue was asking the wrong command for the answer. It now asks Antigravity's protocol server, and a signed-in Antigravity shows as signed in. The same fix applies to Qwen Code, Cursor CLI and Grok CLI.
- **Scan again is quicker.** A scan no longer waits about 25 seconds on that wrong command; on a machine with Antigravity installed it went from about 28 seconds to about 7.
- **Fewer "Probe timed out" messages.** Version and protocol checks get more time when every coding agent starts at once, and checking Antigravity no longer starts its background updater.

## Changed

- **Coding agents you turned off in Providers no longer appear under Agents.** A line below the list names them and links to Providers. One that an employee still uses stays listed.

## Installation

Download `Retinue_0.2.0-beta.8_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows may block Retinue, because it is not code-signed. There is no per-app exception; it runs once Smart App Control is off, or once releases are code-signed.
