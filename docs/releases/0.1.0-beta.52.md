# Retinue 0.1.0-beta.52

An installer fix. Reinstalling Retinue by hand no longer closes and uninstalls it first.

## Fixed

- **Reinstalling no longer removes the app first.** The installer had a step meant for the app's old name. After the rename, it matched Retinue itself, so running the installer by hand over an existing install force-closed Retinue and silently uninstalled it before installing again. Your data was kept, but the step was unnecessary, and it is the kind of behaviour that makes antivirus software suspicious of an installer. It has been removed. Automatic updates were not affected.

## Installation

Download `Retinue_0.1.0-beta.52_x64-setup.exe` and check it against `SHA256SUMS.txt`. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
