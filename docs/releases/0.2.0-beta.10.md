# Retinue 0.2.0-beta.10

Retinue can now add itself to your coding agents, and OpenCode employees start reliably again.

## New

- **Connect coding agents to Retinue in one click.** Settings › Integrations › Retinue MCP now lists the coding agents on this computer: Claude Code, Codex, OpenCode and Cursor. **Connect** adds Retinue to that agent's own settings, so every new session there can see and work with your employees. **Connect all** does every one at once. You no longer need to paste a command into a terminal.
  - Retinue adds one entry named `retinue` and never writes its key into another app's settings.
  - It keeps a backup of the file before its first change. It never touches a file it can't read, and it leaves alone a `retinue` entry you made yourself.
  - **Disconnect** removes only what Retinue added. With the Retinue MCP off, the page offers to remove those entries.
  - Sessions that are already open need a restart to pick it up.
  - For any other MCP app, the command is still there under **Other apps**.

## Fixed

- **OpenCode employees failed at the start of a turn** with "provider protocol error: [hidden] error: Internal service failure". OpenCode 2.3.2 gives up after five seconds if its model list isn't ready, and Retinue was starting a second OpenCode process at the same moment to read that list. Retinue no longer does that when a turn starts. If OpenCode still fails while setting up, Retinue waits a second and tries once more before anything is sent.
- **OpenCode's model list came up empty** with OpenCode 2.3.2, which dropped an option Retinue used. The list works again. If a refresh fails, Retinue keeps the last list it had instead of showing none.
- **Errors from OpenCode, Antigravity and the other ACP agents are readable.** You now see, for example, "OpenCode had an internal error (UnknownError). This is usually temporary: retry the turn.", not a scrambled line.
- **"Ask the CEO to troubleshoot" no longer leaves empty failed conversations.** The report is saved in the CEO's conversation before the CEO starts, so it's there even if the start fails. Pressing the button again opens that same conversation.
- **Gemini no longer appears as a coding agent.** Gemini CLI support ended on 3 November, but an old entry could still show up as "Coding agent" when editing an employee. It's gone. An employee that was set to it now says "Choose a coding agent", and its old conversations stay readable. Antigravity is unaffected.

## Installation

Download `Retinue_0.2.0-beta.10_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows may block Retinue, because it is not code-signed. There is no per-app exception; it runs once Smart App Control is off, or once releases are code-signed.
