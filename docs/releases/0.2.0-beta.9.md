# Retinue 0.2.0-beta.9

Employees on Antigravity can now start and run conversations.

## Fixed

- **An Antigravity employee could not start a conversation.** Sending the first message said "Could not start the conversation". Three things were in the way, all now fixed:
  - Retinue refused the employee's model, effort and instructions for Antigravity before it even started. They are now on, for Antigravity and for Qwen Code, Cursor CLI and Grok CLI (model and instructions; effort only for Antigravity so far).
  - An employee's instructions reached only OpenCode. Other coding agents now get them at the start of each new conversation.
  - Effort was set in a way only OpenCode understands. Antigravity now gets its own thinking level.
- **When a conversation cannot start, Retinue says why**, in the coding agent's or Retinue's own words, instead of only "Could not start the conversation. Try again."

## Installation

Download `Retinue_0.2.0-beta.9_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows may block Retinue, because it is not code-signed. There is no per-app exception; it runs once Smart App Control is off, or once releases are code-signed.
