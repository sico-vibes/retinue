# Retinue 0.2.0-beta.13

Calmer Haze motion, a cleaner other-devices view, and a more faithful browser preview.

## Changed

- **Haze is calmer.** Hover lights are flat colour changes, rows and messages no longer animate in as you move around, and lifts only happen with a real mouse pointer. Dialogs, Schedules cards and the other occasional views still ease in.
- **Schedules** cards rise in a few milliseconds apart and lift slightly on hover.

## Fixed

- **A status label** ("Needs you", "Working") next to an employee's name stays on one line, so the name is no longer clipped.
- **Another machine's conversation** no longer leaves a local conversation highlighted in the sidebar while it is open.
- **Long names and long unbroken text** in another machine's pane and list are cut or wrapped instead of pushing controls out of view.

## For developers

- The browser preview now draws the installed window around the app: title bar, the 1000×680 minimum, and the native acrylic backdrop that Haze tints. `?frame=0` shows the bare page.

## Installation

Download `Retinue_0.2.0-beta.13_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows may block Retinue, because it is not code-signed. There is no per-app exception; it runs once Smart App Control is off, or once releases are code-signed.
