# Retinue 0.2.0-beta.11

Haze has a new look, and OpenCode no longer holds up the launch screen.

## New

- **A new Haze.** The window now has a frame around one rounded page. Rows light up as you hover them, and cards are flat. Switches, menus, dialogs, buttons and text fields have been redrawn to match. The Tasks, Schedules, Usage, employee and Team pages no longer draw outlines. The panel on the right is frosted.
- **A sky on an empty conversation.** A new conversation shows a printed sky with the time and date over it, and the sky's light falls on the columns beside it. Retinue draws the sky itself, so no picture is downloaded. The Haze background picture is back behind the window frame.
- **Settings in a full window.** Settings now fills the window and is grouped into App, Work, Connections, Privacy & security and System, with one row per page. A new **About** page shows the version, with links to the source, the release notes, the licence and a place to report a problem.
- **The profile menu** at the bottom left rises from your profile. When no name is set yet, it asks for one in a small popover, and a long name ends in an ellipsis instead of widening the menu.
- **Haze uses your system font** by default. Inter is still available under Settings › Appearance.

## Fixed

- **The launch screen no longer waits on OpenCode.** It shows the OpenCode model list Retinue already has, instead of waiting for OpenCode to start and list its models. OpenCode 2.x no longer gets an option it dropped.

## Installation

Download `Retinue_0.2.0-beta.11_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows may block Retinue, because it is not code-signed. There is no per-app exception; it runs once Smart App Control is off, or once releases are code-signed.
