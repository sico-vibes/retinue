# Retinue 0.2.0-beta.3

Work with employees on your other machines, and let an employee use the computer on your server as its own.

## New

- **Talk to employees on another machine.** Open an employee under a linked machine in the sidebar. **New conversation** starts one on that machine, **Send** starts a turn there, **Send now** adds to a running one and **Stop** ends it. The other machine runs the work with its own coding agent, files and sign-ins. What this machine may do there is still set on the other machine: View stays read-only, Chat can talk, and Operator can also take conversations over.
- **Works on the computer.** On an employee's page, under the working folder, a new switch appears once a computer on your server is shared with employees. With it on, that employee treats the computer as its workplace: it clones repositories, builds and runs projects there, starts long jobs in the background with a log, and sets up routines for anything on a schedule. The computer wakes when one of its conversations starts, and is never put to sleep by it. Commands still wait for your approval when the employee is set to ask.

## Changed

- A refusal from another machine (for example, a level that doesn't allow it, or a machine that can't be reached) now says what to change, in plain words.

## Before you use it

- Each machine you want to work on needs Retinue running there and paired once with this one, in Settings, Machines. Tailscale is the simplest way to reach it.
- A Linux server can't run Retinue yet. Use **Works on the computer** for work on your server for now.

## Installation

Download `Retinue_0.2.0-beta.3_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
