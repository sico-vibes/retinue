# Retinue 0.1.0-beta.29

The first release under the Retinue name. Many changes since beta.28: a new look system,
a guided tour, a rebuilt bot editor, companion upgrades, resilience work and a new installed
identity. **This release changes where Retinue lives on disk and what the installer is called;
read "Upgrading from Retinue" first.**

## Upgrading from Retinue

- The installer is `Retinue_0.1.0-beta.29_x64-setup.exe`; the app installs to
  `%LOCALAPPDATA%\Retinue` and the executable is `Retinue.exe`.
- A pre-install step stops a running Retinue and runs its uninstaller silently, leaving your
  data in place. On first launch Retinue moves `%LOCALAPPDATA%\com.retinue.desktop` to
  `com.retinue.desktop` and merges `%LOCALAPPDATA%\Retinue` (the database, speech models) into
  `%LOCALAPPDATA%\Retinue`. Old program files are left behind, never copied. The old folders
  are kept; a `migrated-from-retinue.json` marker records what happened.
- A "Start with Windows" entry named Retinue is replaced by one named Retinue.
- **This migration has never run on a real Retinue install before this release.** Back up
  `%LOCALAPPDATA%\Retinue` first if the conversations matter.
- Internal names are unchanged on purpose: the GitHub repository, crate and package names,
  settings keys and environment variables.

## New

- **Retinue and Stone looks.** Retinue (pixel robots, neutral monochrome, light and dark) is
  the primary look; Stone is the previous blob look. Chosen in a new first onboarding step with
  an animated preview, and any time in Settings > Appearance, which also has a live preview, an
  accent colour (neutral, eight colours, custom), theme, text size and density.
- **Bots or blobs, by look.** The wording follows the look, in the app and in what bots are told.
- **Guided tour.** Six stops, started after onboarding, offered to existing users, replayable
  from the profile menu or the command palette. One-time hints for the first permission
  request, first plan, a nearly full context window and the first bot-to-bot message.
- **Bot editor.** Section rail with change dots, live preview, save bar with a change summary
  and Ctrl+S, a discard dialog that lists what you would lose, "Saved" confirmation, an
  instructions editor with counter, presets and history on this device, working-folder recents,
  permissions in plain words, memory and activity on the page, collapsed technical details,
  Duplicate / Export / Archive together, and a create wizard with seven templates.
- **Companion.** "N need you" badge that jumps to the next waiting bot; an approval queue with
  Previous, Next and Later; completion peeks and a Focus mode; a useful Activity tab without the
  experiment flag; chat "Load earlier" and copy; a steadier drop zone; keyboard access and
  focus rings; an offline banner with Retry; snap to screen edges and corners and Reset
  position.
- **Conversation.** Message actions in one order with Retry, expandable delegation chips,
  roster drag and keyboard reordering, density setting, skeleton loaders, plan checklist with
  progress, approval card with command block and copy.
- **Resilience.** Plain-language errors, a reconnect banner, first-scan recovery, uniform undo.
- **Sidebar.** Usage meter for the window closest to its limit, selected-row marker, a Remote
  chip.
- **Remote mode (preview only).** Settings > Remote and a phone-first client exist in the
  browser preview with a simulator. **The desktop app does not host anything**; there is no
  gateway, relay or networking in this build. Design documents, a threat model, an independent
  review and an executable method-tier policy are in `docs/remote/`.
- **Settings.** A dedicated Appearance page, settings search, and a Remote page that explains
  itself when unavailable.

## Changed

- Product name, window titles, tray, installer and shortcuts read Retinue.
- New app icon from the supplied artwork.
- The experimental Retinue toggle is gone (it is the default look now).

## Verification

- Desktop typecheck and 875 tests pass.
- Daemon (157) and storage (92) tests, desktop snap tests (8) and workspace clippy pass.
- Browser preview checked for the look picker, tour, hints, Appearance, Remote host page, phone
  client, bot editor and wizard, companion badge, in both looks.

Unverified: the installer, the pre-install hook and the data migration on a real machine; the
installed native windows (companion drag and snap, tray); anything networked. Known flake: the
mounted desktop tests occasionally time out when the machine is under load and pass on rerun.

## Manual installation

Download `Retinue_0.1.0-beta.29_x64-setup.exe` and verify it against `SHA256SUMS.txt`. The
installer is unsigned (Windows may warn). No updater manifest is published; the signed
`channel-beta` feed remains at beta.6. Install beta.29 manually.
