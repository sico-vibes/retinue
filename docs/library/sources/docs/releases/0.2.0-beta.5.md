# Retinue 0.2.0-beta.5

Retinue on several computers at once: your laptop, your home computer, a server and your phone see the same conversations live, and any of them can carry one on. Employees can also learn skills for you to review, and connectors sign in with your browser.

## New

- **Other computers, live.** A linked computer's conversations update as soon as something changes there, with each step the employee takes and a **Live** mark. When a computer goes offline, its last known conversations stay in its group, greyed, and come back on their own when it returns.
- **Answer another computer's approvals.** When an employee on a linked computer asks for permission, the card appears where you are, with **Allow** and **Deny**.
- **The full work log between your computers.** Your own computers see each other's tool steps, commands and output. Phones and browsers still see only that a tool ran.
- **Start a project on another computer.** From a linked computer's group, **New project** lets you browse the folder that computer shares, use a folder there or clone a repository into it, and start a conversation with one of its employees. It is off until you turn it on in Settings › Machines on that computer, and you choose the one folder other devices may use.
- **Manage another computer's devices.** From a linked computer's group, **Manage** shows its Remote status, its paired devices and their levels, and its activity. You can remove a lost phone, rename a device, change its level or approve one that is waiting. A computer can never change its own pairing or approve another computer.
- **Your phone works on every linked computer.** The phone's picker lists the computer it is paired with and every computer that one is linked to. You can open an employee's conversations there, send, steer, stop and answer approvals, never at a higher level than the phone's own.
- **A server with no screen.** `retinued` can run on a Linux server as a service, paired from its own terminal (`retinued pair`). See *Retinue on a Linux host* in the documentation.
- **Skills your employees learn.** An employee you are working with can save a procedure as a skill. It waits under Skills › To review until you read it, edit it, approve it or forget it, and only the employee that wrote it can use it before then.
- **First tasks for a new project.** An empty conversation suggests three things to do, read from the project itself: its README, its scripts and its latest commit.
- **Connectors sign in with your browser.** Adding a connector that supports it opens your browser to sign in. You can cancel, open the page again or disconnect, and the token is kept in Windows Credential Manager.
- **Earlier messages on the phone.** A long conversation opens at its newest messages, and **Earlier messages** loads the rest.

## Changed

- Settings › Chat has **Context before your message**, off by default for this release. It puts what Retinue tells the employee ahead of your words.
- Results from outside Retinue (web pages, the server's computer, connectors) are marked as data, not instructions, before an employee reads them.
- Each conversation started from another device says where it came from.

## For the curious

- The Retinue MCP has new tools for linked computers: list them, read and start conversations there, wait for a reply, answer approvals, browse and clone, and a diagnostic report for each link.
- `npm run evals` runs five behaviour checks against a real coding agent. It runs only when you start it, and never in CI.

## Installation

Download `Retinue_0.2.0-beta.5_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.

To use several computers, update each of them to this version, then link them in Settings › Machines.
