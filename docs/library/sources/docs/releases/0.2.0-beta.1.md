# Retinue 0.2.0-beta.1

Messages you queue are easier to manage, a usage limit no longer ends your work, more coding agents sit behind switches, and employees can use a computer on your own server.

## New

- **Send a queued message into a running turn.** Queued messages show as rows above the message box. **Send now** hands one to the employee while it is still working, in one step. Where a coding agent cannot take a message mid-turn, the button says **Stop and send**. Claude Code and OpenCode steering are switches under Settings › Coding agents › Providers.
- **Resume after a usage limit.** When a conversation hits a usage limit, the message box says when it resets. You can have the conversation resume by itself at that time, or snooze it.
- **Providers page.** Claude Code, Codex and OpenCode are always on. Qwen Code, Cursor, Grok Build and Antigravity are off until you switch them on.
- **Sign in to an account from the app.** Accounts opens the coding agent's own sign-in in a terminal for the account you picked, then checks it.
- **A computer on your own server.** Settings › Integrations › Computer links a Harbor computer by address and token. You can see its state, wake it, put it to sleep and run its routines. Switch on **Let employees use this computer** and new conversations get tools to work on it. A command still waits for your approval when the employee is set to ask. With no server yet, the page gives you a prompt to hand to a coding agent on your server, which sets the computer up.
- **Local servers.** When an employee starts a dev server, the conversation's side panel lists it with a link that opens in your browser.
- **Review by scope.** The changes view can show uncommitted work, the last turn, the whole branch or the last commit.
- **Snooze a conversation** from the list to stop it asking for your attention for a while.

## Changed

- Conversations that need you sort to the top.
- A step from a turn that ended no longer reads as still working.
- A resumed long conversation gets three minutes to start answering, not 45 seconds.
- The CEO's briefs to employees name the task, what not to touch, the commands to run and what to report.

## Fixed

- A long queued message no longer runs past the edge of the message box.
- The queue no longer disappears when the app first loads.
- The CEO now sees an employee hired into a project as part of that project.
- Onboarding in the Haze look showed light text on a white window.
- Dropdowns in the hire dialog opened behind it.
- The blank profile picture now fills its circle.

## Not in this release yet

- The computer's screen opens in your browser. Watching it inside Retinue, and taking control from there, comes in a later beta.
- Steering in OpenCode and linking a computer have been tested against stand-ins, not yet on every real setup. Please report what you see.

## Installation

Download `Retinue_0.2.0-beta.1_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
