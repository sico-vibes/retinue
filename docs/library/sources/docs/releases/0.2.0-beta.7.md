# Retinue 0.2.0-beta.7

Install and update your coding agents from inside Retinue, and bring your earlier Claude Code, Codex and OpenCode conversations into your projects.

## New

- **Install and update coding agents.** Settings › Coding agents › Providers has an **Install…** or **Update…** button on each coding agent. Before anything happens, a card says what will be done: for a copy you installed yourself, which tool updates it; for a copy Retinue keeps, the version, where it comes from, its size, the start of the publisher's checksum and the folder it goes in. Retinue checks the download against that checksum before anything runs. Progress shows as it goes ("Downloading 41% · 26 MB of 62 MB", then "Checking the download", "Installing", "Done"). There is no terminal window and no administrator prompt.
  - Your own copy is never updated while an employee is using it.
  - **Remove Retinue's copy** deletes only the copy Retinue installed.
  - Cursor, Grok, Antigravity and Qwen open their install page; Retinue does not download those yet.
- **Keep a coding agent up to date.** A switch on the same card. After your first install or update there, Retinue checks every six hours and updates on its own from the same source. A different source still asks you first, and it never installs an agent you don't have.
- **Import conversations, by project.** Choose **Import conversations…** from the + menu. Pick how far back to look, then your earlier conversations are grouped by folder ("Already a project", "New project" or "Folder missing"), with a search box and **Import all** for a whole folder.
- **See who gets each conversation before anything is imported.** "Share them out" suggests an employee for each conversation, and says why. Change any of them, then import. If no employee uses that coding agent yet, you can hire one right there.
- **Carry on an imported conversation.** An imported conversation that can't continue here shows **Continue with …**, which picks it up in the same coding agent when its file is still on this computer, and **Give this to another employee…**, which starts a new conversation with a short summary in the message box. Nothing is sent until you send it.

## Changed

- An imported conversation keeps its "read-only history" bar after Retinue restarts.

## Installation

Download `Retinue_0.2.0-beta.7_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
