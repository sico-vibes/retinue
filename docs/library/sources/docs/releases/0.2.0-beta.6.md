# Retinue 0.2.0-beta.6

A faster Retinue. Long conversations open and scroll about ten times faster, replies stream with fewer redraws, the app starts sooner, and nothing Retinue runs opens a console window any more.

## New

- **Follow-up suggestions.** After an employee finishes, the composer offers one next prompt. Press Tab or Right Arrow to use it, or Escape to dismiss it.
- **Why a turn stopped.** When a turn ends with an error, the chat and the sidebar say why, in one sentence, instead of only "Stopped with an error".
- **Pi's real logo** on the Providers page.

## Changed

- **Long conversations are much faster.** A conversation shows its newest 80 messages and loads earlier ones as you scroll up, keeping your place. On a 1,000-message conversation, opening it went from about 10 seconds to about 2, and typing in the composer from about a second per key to under a tenth of one.
- **Replies stream in small batches.** The text of a reply is saved and drawn about 25 times a second instead of once per word, which keeps the window responsive while an employee writes.
- **A quicker start.** Retinue remembers each coding agent's version check between launches, checks the database's integrity in the background, and only prepares the agents your recent and running conversations use. **Scan again** still checks every agent afresh. The opening animation is shorter.
- **No console windows.** Every program Retinue starts, including updating a coding agent's CLI, now runs hidden.
- **Turned-off providers stay quiet.** Retinue no longer checks a provider you turned off, and Doctor no longer warns about one. A provider is never listed twice.
- **Resume says what happened.** The composer's Resume button reports when the queue could not continue, instead of doing nothing.
- **Send now works for messages from other apps.** A message sent through the Retinue MCP (for example from Claude Code) can now go into the running turn, and it is labelled "via Claude Code".
- Long file paths stay inside their rows in Review changes.
- The window lightens its glass effects for a moment when your computer is busy, so scrolling stays smooth.

## For the curious

- The daemon can install and update the coding-agent CLIs itself, either through the update tool you already use or as a copy of its own, checked against the publisher's digest, with no terminal and no administrator prompt. On a server, use `retinued agents install <provider>`. The buttons in Settings › Agents come in a later release.
- The daemon can also read your earlier Claude Code, Codex and OpenCode conversations and bring them into a project as read-only history, suggesting which employee should own each one. The screen for it comes in a later release.
- The web preview has a **Demo** badge that can show every screen, state and error in the app.

## Installation

Download `Retinue_0.2.0-beta.6_x64-setup.exe` and check it against `SHA256SUMS.txt`. Retinue 0.1.0-beta.32 and later update themselves. The installer is not code-signed yet:

- Microsoft Defender may report it as `Program:Win32/Contebrew.A!ml`. This is a false positive from its automatic scanner. To keep the file, open Windows Security › Protection history, select the entry and choose **Allow on device**.
- SmartScreen may then say Windows protected your PC. Choose **More info** › **Run anyway**.
- On a PC with **Smart App Control** turned on, Windows blocks unsigned installers with no way to run them. Retinue can be installed there once releases are code-signed.
