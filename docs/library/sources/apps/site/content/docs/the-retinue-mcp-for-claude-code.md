# The Retinue MCP for Claude Code

Retinue includes a small connector, called the Retinue MCP, that lets Claude Code reach the employees on your Retinue team. Once it is connected, Claude Code can talk to those employees from its own session, for example to ask one for a second opinion.

## Steps: connect it

1. Open Settings, then Connections, then Integrations, then Retinue MCP.
2. Follow the steps on that page to connect Claude Code to Retinue.
3. Start Claude Code in a project. It can now reach the Retinue team.
4. Check the connection on the same page before you rely on it.

## Good to know

- The connector only reaches employees on your own team. It does not give Claude Code access to other computers or accounts.
- Anything an employee does through the connector still follows that employee's approval mode.
- If Claude Code does not see the team, restart Claude Code, then check the connection again.
