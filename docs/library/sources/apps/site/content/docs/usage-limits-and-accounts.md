# Usage limits and accounts

Each coding agent has its own usage limits and its own account. Retinue shows what it can about your usage, and it lets you sign in from the app. It never shows a number it cannot know, and it never shows a limit as zero when it is unknown.

## Check your usage

Open **Usage** from the sidebar. It lists each coding agent you use and what it reports about your limits.

If a number is missing, the coding agent did not report it. Retinue says so rather than guessing.

## Sign in to an account

1. Open Settings, then Coding agents, then Accounts.
2. Choose the account you want, and use its sign-in option.
3. The coding agent's own sign-in opens in a terminal window. Finish the sign-in there.
4. Retinue checks the sign-in once it is done.

Your sign-in belongs to the coding agent. Retinue does not copy it.

## Usage limits in a conversation

When a conversation reaches a usage limit, the message box shows when the limit resets. You can let the conversation resume by itself at that time, or snooze it. See [Messages, the queue and steering](/docs/messages-the-queue-and-steering/).

## Good to know

- Retinue can show usage bars from your coding agent's sign-in. This is off by default and only happens if you choose it. When it is on, Retinue sends the sign-in only to that coding agent's own usage page, and does not store it.
- If a coding agent is signed out, Retinue shows it as needing a sign-in rather than as working.
