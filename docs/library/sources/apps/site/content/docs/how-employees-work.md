# How employees work

An employee in Retinue is a team member you configure once and then work with many times. It is made of four parts. You can change each one.

![An employee's page](/docs/docs-team-dark.webp)

## The four parts

- **Role and personality.** The role says what the employee is for, such as backend engineer or code reviewer. The personality sets its tone, for example steady, playful or blunt. Both are shown on its page.
- **Skills.** A skill is a set of instructions the employee follows for a kind of task, such as writing tests or reviewing a pull request. Each role comes with a sensible set. You can add more from the shared pool.
- **Model.** The model is the AI model the coding agent uses for the employee's work. Some agents let you choose a model and an effort level. Retinue shows what your agent offers and leaves the rest alone.
- **Coding agent.** This is the program that does the work: Claude Code, Codex or OpenCode. It runs on your computer and uses the sign-in you already gave it.

## What an employee keeps

- Its own conversations, with their history.
- Its working folder, which is the project folder it works in.
- Its approval mode, which says what it may do without asking. See [Approvals and permissions](/docs/approvals-and-permissions/).
- Its memory of your preferences for that employee.

## What is shared

Skills are shared across the team, so you write a skill once and any employee can use it. Your coding agent's sign-in is not copied into Retinue. Each coding agent keeps its own.

## Good to know

- Changing an employee's coding agent or model affects new conversations. Existing conversations keep what they started with.
- An employee's memory belongs to that employee. Other employees do not see it.
- To change any of these parts, see [Hiring and editing employees](/docs/hiring-and-editing-employees/).
