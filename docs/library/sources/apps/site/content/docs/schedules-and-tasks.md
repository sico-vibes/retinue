# Schedules and tasks

Schedules let an employee do a piece of work on its own, at a time you choose. Tasks help you keep track of the work the team has to do. Both are in the sidebar.

![The schedules page](/docs/docs-schedules-dark.webp)

## Steps: create a schedule

1. Open **Schedules** from the sidebar.
2. Choose the employee and write what it should do, for example "Run the tests every night and report any failures."
3. Choose when it runs.
4. Save it, then check the Schedules page for its runs.

## Pause schedules

To stop every scheduled run, use **Pause all agents**. Scheduled runs pause with it, until you turn schedules back on.

## Tasks

Open **Tasks** from the top bar to see the team's work on one board.

![The tasks board](/docs/docs-tasks-dark.webp)

## Good to know

- Scheduled runs use safe actions only, even if the employee is set to **Full access**. A risky action waits for you.
- Check a schedule's runs after it fires, so you know what the employee reported.
